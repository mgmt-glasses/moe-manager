# MVP 仕様サマリー

このドキュメントは、既存の `detail/仕様書.md` をもとに、MVP の目的と実装対象を短く確認できるように整理したものです。

## MVP の目的

MVP では、複雑な育成や高度な分析ではなく、以下の体験を最小構成で成立させます。

> 社長の行動に秘書キャラが反応してくれる。

## MVP の一言定義

MBTI 別に選べる二次元秘書キャラが、社長のタスク、娯楽時間、統計を見ながら、チャットとボイスで行動を支えてくれる最小アプリ。

## 実装する機能

| 機能 | 概要 |
| --- | --- |
| MBTI 別キャラ選択 | 初期設定で秘書キャラを選択する。まずは代表的な 4 タイプ程度から開始する。 |
| チャット | 選択中キャラの MBTI、性格、口調を反映して返答する。 |
| ボイス | チャット返信をキャラ別ボイスで読み上げる。 |
| タスク管理 | タスク登録、一覧、完了、削除、完了率計算を行う。 |
| 娯楽時間管理 | 日付ごとの娯楽時間を手動入力し、目標との差分を出す。 |
| 統計管理 | 今日と過去 7 日分のタスク、娯楽時間、サマリーを確認する。 |
| チャットログ | ユーザ発言、キャラ返答、発言日時、ボイス対象テキストを保存する。 |

## 初期キャラ案

| MBTI | キャラ方向性 |
| --- | --- |
| ISTJ | 真面目で几帳面な管理型秘書 |
| ENFJ | 励まし上手で面倒見がいい秘書 |
| INTJ | 冷静で戦略的な成果重視秘書 |
| ENTP | 軽快でアイデア豊富な秘書 |

## 画面構成

| 画面 | 主な内容 |
| --- | --- |
| 初期設定 | ユーザ名、呼び名、目標娯楽時間、使用キャラ |
| キャラ選択 | キャラ一覧、MBTI、説明、口調、ボイスサンプル |
| チャット | キャラ表示、履歴、入力欄、送信、ボイス再生、今日の簡易ステータス |
| タスク | タスク追加、未完了一覧、完了一覧、完了、削除 |
| スクリーンタイム入力 | 日付、娯楽時間、目標時間、保存、差分 |
| 統計 | 完了数、未完了数、完了率、娯楽時間、過去 7 日、日次サマリー |
| チャットログ | 日付別の会話履歴、発言者、メッセージ、発言時刻、ボイス再生対象 |

## MVP で割り切ること

- キャラは最初から全 16 タイプを用意しなくてよい。
- 娯楽時間は自動取得ではなく手動入力から始める。
- タスク状態はまず `todo` と `done` の 2 状態でよい。
- 統計は専用集計テーブルではなく、既存記録からの都度計算を基本とする。
- 認証はユーザー別 API で Firebase ID token を必須化済み（[ADR-0010](adr/0010-firebase-auth-boundary.md)）。トークン失効の即時反映やロール認可は将来対応とする。

`detail/仕様書.md` にある「統計データを保存する」記述は、MVP では「統計として表示できる状態にする」と読み替えます。
永続化は `tasks` と `screentime_records` を優先し、専用統計テーブルは必要になってから追加します。
